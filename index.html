Topic 01 • LIFO Principle

Stack Data Structure

▶ Try Live Demo (Stack)

What is a Stack?

A Stack is a linear data structure that follows the LIFO (Last In, First Out) principle. Both insertion (Push) and deletion (Pop) happen at only one end, called the TOP.

Real-Life Examples

🍽️ Stack of cafeteria plates
↩️ Undo (Ctrl+Z) in a text editor
🌐 Browser Back button history
📞 Function Call Stack in recursion

Operations & Complexity

Operation Description Time Space
Push(x)Insert element x onto the TOP of the stackO(1)O(1)
Pop()Remove and return the TOP element (Underflow if empty)O(1)O(1)
Peek() / Top()Inspect the TOP element without removing itO(1)O(1)
isEmpty()Check if top == -1 (no elements stored)O(1)O(1)
isFull()Check if top == capacity - 1 (array stack)O(1)O(1)

Visual Diagram: Push & Pop at TOP

a) Array-Based (Static) Stack

Uses a fixed-size contiguous array stack[MAX] and an integer variable top initialized to -1. Extremely fast and cache-friendly, but can trigger Stack Overflow if capacity is exceeded.

b) Linked-List-Based (Dynamic) Stack

Implemented as a Singly Linked List where Push and Pop operate at the HEAD (TOP) node in O(1) time. Grows and shrinks dynamically in memory with no fixed capacity limit.

Key Computer Science Applications of Stack

🧮 Expression Evaluation: Evaluating Postfix / Prefix arithmetic expressions
🔄 Syntax Conversion: Infix to Postfix / Prefix conversion using operator precedence
🧩 Parentheses Matching: Validating balanced brackets {[()]} in compilers
🔁 Recursion & Backtracking: Storing return addresses and local variables on the Call Stack

Push(10)

top = 0, stack[0] = 10

Step 2
Push(20)

Step 3

Python — Array-Based Stack Implementation 
class Stack:
    def __init__(self, capacity=8):
        self.stack = []
        self.capacity = capacity

    def push(self, val):
        if len(self.stack) >= self.capacity:
            raise OverflowError("Stack Overflow!")
        self.stack.append(val)           # O(1) push at TOP

    def pop(self):
        if not self.stack:
            raise IndexError("Stack Underflow!")
        return self.stack.pop()          # O(1) pop from TOP

    def peek(self):
        return self.stack[-1] if self.stack else None
Topic 02 • FIFO Principle

Queue Data Structure

▶ Try Live Demo (Queue)

What is a Queue?

A Queue is a linear data structure that follows the FIFO (First In, First Out) principle. New elements enter at the REAR (Enqueue) and existing elements leave from the FRONT (Dequeue).

Real-Life Examples

🎟️ Movie ticket counter queue
🖨️ Office document printer spooler
⚙️ CPU process & task scheduling
🎧 Customer support call hold line

Operations & Complexity

Operation Description Time Space
Enqueue(x)Insert element x at the REAR endO(1)O(1)
Dequeue()Remove and return element from the FRONT endO(1)O(1)
Front() / Peek()Read the element currently at FRONT without removingO(1)O(1)
isEmpty()Check if front == -1 or size == 0O(1)O(1)
isFull()Check if queue has reached maximum capacityO(1)O(1)

Visual Diagram: FIFO Queue (FRONT & REAR)

a) Simple (Linear) Queue

Standard FIFO array queue where front and rear move forward linearly. Once rear reaches the last index, empty slots left behind by prior dequeues cannot be reused without resetting.

b) Circular Queue (Solves Wasted Space)

Connects the last index back to index 0 in a ring using modulo arithmetic: rear = (rear + 1) % N. Reuses freed front slots automatically.

c) Priority Queue

Each element is associated with a priority score. Elements with the highest priority are dequeued first (e.g., hospital emergency room triage, Dijkstra's shortest path).

d) Double-Ended Queue (Deque)

Allows insertion and deletion at both FRONT and REAR ends. Includes:
• Input-Restricted Deque: Insert at one end only, delete from both.
• Output-Restricted Deque: Insert at both ends, delete from one end only.

Step-by-Step Worked Trace: Enqueue(5) → Enqueue(10) → Enqueue(15) → Dequeue()

Step 1
Enqueue(5)

[ 5 ]

front = 0, rear = 0

Step 2
Enqueue(10)

[ 5 | 10 ]

front = 0, rear = 1

Step 3
Enqueue(15)

[ 5 | 10 | 15 ]

front = 0, rear = 2

Step 4
Dequeue() → Returns 5

[ 10 | 15 ]

5 leaves FRONT; front = 1, rear = 2

Python — Circular Queue Implementation 
class CircularQueue:
    def __init__(self, capacity=8):
        self.q = [None] * capacity
        self.cap = capacity
        self.front = self.rear = -1
        self.size = 0

    def enqueue(self, val):
        if self.size == self.cap:
            raise OverflowError("Queue is Full!")
        if self.front == -1:
            self.front = 0
        self.rear = (self.rear + 1) % self.cap  # Modulo wrap-around
        self.q[self.rear] = val
        self.size += 1

    def dequeue(self):
        if self.size == 0:
            raise IndexError("Queue is Empty!")
        val = self.q[self.front]
        self.front = (self.front + 1) % self.cap
        self.size -= 1
        return val
Topic 03 • Dynamic Node Pointers

Singly Linked List

▶ Try Live Demo (Linked List)

What is a Singly Linked List?

A Singly Linked List is a linear collection of dynamic nodes where each node holds a data value and a next pointer to the following node. HEAD points to the first node, and the last node points to NULL.

Real-Life Examples

🚆 Train coaches coupled together
🗺️ Treasure hunt where each clue points to next
🎵 Music playlist "Play Next" chain
🔗 Blockchain / Git commit history chain

Operations & Time Complexity

Operation Description Time
Insert at HeadCreate node, point newNode.next = head, update headO(1)
Insert at TailTraverse from HEAD to last node, link last.next = newNodeO(n)
Insert at PositionTraverse to index pos - 1 and re-wire pointersO(n)
Delete at HeadUpdate head = head.next in constant timeO(1)
Delete by ValueSearch for matching node and bypass it via prev.nextO(n)
Search / TraverseFollow curr = curr.next until value or NULLO(n)
ReverseFlip every node's next pointer in-place using prev, curr, nextO(n)

Visual Diagram: [Data | Next] Node Chain

a) Singly Linked List (Focus of this site)

Each node contains [data | next]. Traversal is strictly one-way (forward) from HEAD to NULL.

HEAD → [10|•] → [20|•] → [30|•] → NULL

b) Doubly Linked List

Each node stores 3 fields: [prev | data | next], allowing bidirectional traversal both forward and backward.

NULL ← [•|10|•] ⇄ [•|20|•] ⇄ [•|30|•] → NULL

c) Circular Singly Linked List

The last node's next pointer points back to the HEAD node instead of NULL, forming a continuous loop.

HEAD → [10|•] → [20|•] → [30|•] ↩ (back to HEAD)

d) Circular Doubly Linked List

Combines doubly linked nodes with circular wrap-around: tail.next points to HEAD and head.prev points to TAIL.

↺ [•|10|•] ⇄ [•|20|•] ⇄ [•|30|•] ↻

Comparison: Array vs. Singly Linked List

Feature Array Singly Linked List
Memory LayoutContiguous block in memoryNon-contiguous nodes scattered in heap memory
Random Access (Index i)O(1) direct index lookup arr[i]O(n) sequential traversal from HEAD
Insert / Delete at StartO(n) (requires shifting elements)O(1) (just pointer reassignment)
Size FlexibilityFixed size (or expensive resizing)Dynamic size; grows & shrinks per node

Worked Example: Insert 10, 20, 30 at Tail → Insert 5 at Head → Delete 20

Step 1
Insert Tail: 10, 20, 30

HEAD → [10] → [20] → [30] → NULL

3 nodes linked sequentially

Step 2
Insert 5 at Head (O(1))

HEAD → [5] → [10] → [20] → [30] → NULL

5.next = 10, HEAD = 5

Step 3
Delete Value 20 (O(n))

HEAD → [5] → [10] → [30] → NULL

Node [10].next bypasses 20 to point to [30]

Python — Node Structure & Insert Operations 
class Node:
    def __init__(self, data):
        self.data = data
        self.next = None

class SinglyLinkedList:
    def __init__(self):
        self.head = None

    def insert_at_head(self, data):
        new_node = Node(data)
        new_node.next = self.head   # O(1) pointer link
        self.head = new_node

    def insert_at_tail(self, data):
        new_node = Node(data)
        if not self.head:
            self.head = new_node
            return
        curr = self.head
        while curr.next:            # O(n) traversal to last node
            curr = curr.next
        curr.next = new_node
Topic 04 • Recursive Divide & Conquer

Tower of Hanoi

▶ Try Live Demo (Tower of Hanoi)

Definition & The 3 Golden Rules

Tower of Hanoi is a mathematical recursion puzzle consisting of three rods (A = Source, B = Auxiliary, C = Destination) and n discs of graduated sizes.

1️⃣ Move only one disc at a time.
2️⃣ Only the topmost disc of any rod can be moved.
3️⃣ A larger disc may never be placed on top of a smaller disc.
⏱️ Complexity: Time O(2ⁿ) • Space O(n)

Minimum Moves Formula: 2ⁿ − 1 (n = 1 to 7)

Discs (n) Formula (2ⁿ − 1) Minimum Moves
n = 12¹ − 11 move
n = 22² − 13 moves
n = 32³ − 17 moves
n = 42⁴ − 115 moves
n = 52⁵ − 131 moves
n = 62⁶ − 163 moves
n = 72⁷ − 1127 moves

Visual Diagram: 3-Subproblem Recursive Strategy

a) Classic 3-Peg Tower of Hanoi

Invented by Édouard Lucas in 1883. Uses 3 rods and requires exactly 2ⁿ − 1 optimal moves.

b) 4-Peg Version (Reve's Puzzle)

Adds a 4th peg and is solved via the Frame–Stewart algorithm, dramatically reducing the required moves compared to 3 pegs.

c) Cyclic Hanoi

Rods are arranged in a circle (A → B → C → A) and discs may only move in a single clockwise direction.

d) Multi-Peg & Magnetic / Colored-Disc Variations

Discs have colored sides or polarity rules restricting which face may touch another disc.

Real-Life Connections

💾 Grandfather-Father-Son Tape Backup Rotation: Magnetic tape backup scheduling
🧠 Neuropsychological Testing: Assessing executive planning and working memory
🌳 Recursion & Call Tree Mastery: Visualizing binary recursion trees and base cases
🔢 Gray Code & Binary Counter: The bit flipped at step k tells which disc to move!

Python — 3-Step Recursive Tower of Hanoi Solver 
def tower_of_hanoi(n, source, auxiliary, destination):
    # Base Case: Only 1 disc left to move
    if n == 1:
        print(f"Move disc 1 from {source} to {destination}")
        return

    # Step 1: Move top (n - 1) discs from Source to Auxiliary
    tower_of_hanoi(n - 1, source, destination, auxiliary)

    # Step 2: Move largest disc n from Source to Destination
    print(f"Move disc {n} from {source} to {destination}")

    # Step 3: Move the (n - 1) discs from Auxiliary onto Destination
    tower_of_hanoi(n - 1, auxiliary, source, destination)

# Run for 3 discs (prints all 7 moves)
tower_of_hanoi(3, 'A', 'B', 'C')
